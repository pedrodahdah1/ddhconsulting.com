# DDH Consulting

Source for ddhbiconsulting.com. Pushes to `main` deploy to GitHub Pages.

The site presents DDH as four connected reporting packages for healthcare organizations, built inside the client's accounts and run with their team. Fees are not published. The path into a conversation is the Reporting Review application. The contact form remains for people who prefer to write.

- `index.html` — main site
- `apply.html` — Reporting Review application. Reviewed within 2 business days.
- `checkup.html` — Reporting Health Check. Results point to the Reporting Review. It is also the pointer when an engagement is not a fit.
