# DDH Consulting

Source for ddhbiconsulting.com. Pushes to `main` deploy to GitHub Pages.

The site presents DDH as a fractional data lead for healthcare operators. Fees are not published. The path in is a free Reporting Review request. People who prefer to write can email contact@ddhbiconsulting.com.

- `index.html`: main site
- `apply.html`: Reporting Review request. We reply within 2 business days.
- `checkup.html`: Reporting Health Check. Results point to the Reporting Review.
- `briefing.html`: scheduled AI briefing, including Path A and Path B.
- `privacy.html`: what the forms collect.
